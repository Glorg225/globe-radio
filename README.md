# Радио планеты (рабочее название)

Веб-сервис: 3D-глобус с живыми радиостанциями мира. Нажал на точку — слушаешь эфир этого города, а рядом видишь карточку места (время, погода, факт). Режим «Учу язык» показывает только станции на нужном языке.

Бесплатно: сайт на статическом хостинге + открытые данные (Radio Browser API и др.).

## Структура
- `docs/01_brainstorm.md` — брейншторм функций и принятые решения
- `docs/02_tz.md` — техническое задание для агента-программиста (следующий этап)
- `docs/03_design.md` — утверждённая дизайн-спецификация (цвета, шрифты, размеры, экраны)
- `design/mockups/` — исходники утверждённого макета (4 экрана)
- Макет на полотне: https://claude.ai/artifact/PwLFJ1sGxMXuSFNSEcK84U
- `src/` — код приложения; `locales/` — тексты интерфейса; `scripts/` — ежедневный снимок станций; `tests/` — тесты
- `docs/superpowers/plans/` — планы реализации

## Запуск локально
Нужен Node.js 22+.

```bash
npm install
npm run snapshot   # скачать станции из Radio Browser в public/data/
npm run dev        # http://localhost:5173
npm test           # тесты
npm run build      # сборка в dist/
```

## Хостинг: GitHub Pages
Бесплатно, с HTTPS. Тот же GitHub Actions раз в сутки скачивает свежий снимок станций и публикует сайт — один конвейер, без отдельных сервисов (`.github/workflows/deploy.yml`).

Первая публикация: создать репозиторий на GitHub, отправить код в ветку `main`, в настройках репозитория **Settings → Pages → Source: GitHub Actions**.

## Как обновить снимок станций
Автоматически — каждый день в 03:17 UTC. Вручную — **Actions → build-and-deploy → Run workflow**.
Если Radio Browser недоступен, сайт собирается с последним опубликованным снимком (в логе будет предупреждение).

**Важно:** GitHub отключает ежедневный запуск, если в репозитории 60 дней не было ни одного коммита (придёт письмо). Чтобы включить снова — **Actions → build-and-deploy → Enable workflow** или сделать любой коммит.
Отчёт снимка (число станций, стран, языков, нераспознанные названия языков) — в логе шага `npm run snapshot` и в `public/data/meta.json`. Частые нераспознанные языки добавляются в словарь `src/data/languages.ts`.

## Данные
- `public/data/places.json` — места на карте (город, регион или центр страны, число станций, популярность). Грузится сразу, ~170 КБ в сжатом виде.
- `public/data/stations/<CC>.json` — станции одной страны, грузятся по клику на место этой страны.
- `public/data/meta.json` — отчёт снимка: сколько станций размещено по координатам, по региону и в центре страны, нераспознанные регионы и языки.
- Перед воспроизведением свежий адрес потока берётся у Radio Browser (`/json/url/<id>`, все зеркала параллельно, до 3 с); если API не ответил — адрес из снимка.

## Справочник городов и регионов (GeoNames)
`data/gazetteer.json` собран из GeoNames (CC BY 4.0): города от 15 000 жителей, регионы, русские названия. По нему станции без координат размещаются по полю региона.
Обновлять раз в полгода: `npm run gazetteer` (один раз скачивает ~200 МБ в `.cache/`; нужен `tar` с поддержкой zip — есть в Windows 10+ и macOS), затем закоммитить `data/gazetteer.json`. Если в `meta.json` растёт список нераспознанных регионов — повод обновить справочник.

## Текстура Земли
`public/textures/earth-night.jpg` — NASA Black Marble (общественное достояние), взята из примеров three-globe.

## Карточка места
- Часовой пояс и названия статей Википедии для каждого места берутся из GeoNames при ежедневном снимке и лежат в файлах стран (`stations/<CC>.json`, поле `places`). Первая загрузка сайта от этого не растёт.
- Статья ищется так: русская → русская через межъязыковую ссылку английской → английская (с пометкой «Статья на английском»). Ответы Википедии хранятся в браузере 30 дней.
- Флаги — набор flag-icons (MIT), SVG; загружается только флаг нужной страны.
- Для мест «страна» время показывается, только если у страны один часовой пояс.

## Режим «Учу язык»
- У каждого места в `places.json` есть счётчики языков станций (`"es:12,ca:3"`, +~13 КБ gzip); из них в браузере строится список языков с числом станций и стран.
- В режиме карта рисует два слоя: все места приглушённо и места выбранного языка бирюзовым; список места и «Следующая на …» берут только станции этого языка.
- Выбранный язык запоминается в браузере (`learnLang`); если такого языка больше нет в данных, режим сбрасывается.
- Фразы «на испанском», «на иврите» склоняются правилом из `src/i18n/ru-grammar.ts` (для других языков интерфейса понадобятся свои правила).

## Нерабочие станции
Если поток не заиграл за 8 секунд или оборвался, станция скрывается из «Следующая рядом» на 12 часов (решение заказчика) — только в этом браузере.

## Как добавить язык интерфейса
1. Скопировать `locales/ru.json` в `locales/<код>.json` и перевести значения (ключи не менять).
2. Добавить код в `SUPPORTED_LOCALES` (`src/app/config.ts`) и в `catalogs` (`src/app/main.ts`).
3. Для языков с письмом справа налево (`ar`) направление включается автоматически.

## Почему без фреймворка
Экран — несколько независимых панелей вокруг холста с глобусом. Чистый TypeScript + Vite даёт минимальный размер кода, что важно для требования «первый показ меньше 3 секунд».

## Название проекта
Название «Радио планеты» — рабочее. Меняется в одном месте: ключ `app.name` в `locales/*.json`. Технический идентификатор (`APP_ID` в `src/app/config.ts`) от названия не зависит.
