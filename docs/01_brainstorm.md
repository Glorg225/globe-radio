# Радио планеты — брейншторм функционала

*Дата: 03.10.2026. Этап: обсуждение (до ТЗ).*

## 1. Суть в одной фразе
Крутишь глобус, нажимаешь на светящуюся точку и слушаешь живое радио из любого города мира.

## 2. Что уже есть на рынке
| Сервис | Что делает | Слабые места |
|---|---|---|
| **Radio Garden** | Глобус с точками-станциями, поиск, избранное. Сайт бесплатный, в приложениях есть платный Premium | Много нерабочих потоков; кроме «найти и слушать» почти ничего нет; нет фильтров по жанру и языку |
| **Radiooooo** | «Машина времени»: музыка по стране и десятилетию, режим «такси» по нескольким странам | Не живое радио, а подборки треков; после 7 дней пробного периода платная подписка |

**Вывод:** «глобус + радио» уже есть, поэтому просто повторить Radio Garden неинтересно. Нам нужны 2–3 своих фишки.

## 3. Источник данных
**Radio Browser API** — бесплатная открытая база интернет-радиостанций.
- По каждой станции есть название, страна, язык, теги (жанры), координаты, голоса, популярность, кодек, битрейт, флаг «работает при последней проверке», иконка, поддержка HLS.
- Есть счётчик кликов и голосование (не чаще раза за период с одного IP). Работа сервиса «без гарантий», возможны простои.

## 4. Технические ограничения (важно для решений)
1. **HTTP и HTTPS.** Наш сайт будет на HTTPS, а браузер не даёт проигрывать на нём потоки по HTTP, а таких станций много. Варианты:
   - (а) показывать только HTTPS-станции: просто, но часть станций пропадёт;
   - (б) бесплатный прокси на Cloudflare Worker: станций больше, но есть риск упереться в лимиты и правила Cloudflare.
2. **Мёртвые потоки.** Фильтруем по флагу «работает при последней проверке»; если поток не запустился за 5 секунд, автоматически переключаем на соседнюю станцию.
3. **Координаты есть не у всех станций.** Для остальных ставим точку в центре города или страны.
4. **«Что сейчас играет» (название песни)** браузер напрямую почти не получает. Переносим в поздние версии.

## 5. Идеи функций

### A. База (MVP)
- 3D-глобус со станциями-точками; яркость точки = популярность.
- Клик по точке → список станций города → плеер (play/pause, громкость).
- Поиск по названию, городу, стране.
- Избранное и история (хранятся в браузере).
- «Случайная станция» — кнопка «удиви меня».
- Ссылка на станцию: «Слушаю радио из Улан-Батора 👉 ссылка».
- Мобильная версия: глобус сверху, плеер внизу.

### B. Фишки-отличия (выбрать 2–3)
1. **🌅 «Утро планеты»** — день и ночь на глобусе плюс режим «слушать там, где сейчас утро»: станция сама переезжает вслед за рассветом.
2. **✈️ «Кругосветка»** — автопутешествие: каждые N минут переключаемся на станцию восточнее. Кругосветка за вечер.
3. **🗣️ «Учу язык»** — фильтр «только станции на испанском / английском / японском…». Глобус показывает, где говорят на этом языке. Это реальная польза для тех, кто учит язык.
4. **🎷 Фильтр по жанру и настроению** — «джаз мира», «новости», «классика», «спокойное». Глобус подсвечивает только подходящие станции.
5. **📍 Карточка места** — пока играет станция: местное время, погода, короткий факт о городе из Википедии, флаг. Слушаешь и узнаёшь мир.
6. **📊 «Пульс эфира»** — статистика: сколько станций в каждой стране, самые популярные станции мира сегодня, самый «радийный» город.
7. **😴 Таймер сна** и **📱 установка на телефон (PWA)** с фоновым воспроизведением.

### C. Позже (версия 2+)
- «Что сейчас играет» (название трека).
- Голосование за станции (через API Radio Browser).
- Аккаунты и синхронизация избранного (Supabase).
- Совместное прослушивание: «слушай со мной» по ссылке.

### D. Не делаем
- Запись эфира (юридический риск).
- Собственный каталог станций (берём готовый).
- Комментарии и чат (модерация).

## 6. Как может выглядеть
- **Тёмная «космическая» тема.** Ночная Земля с огнями городов, станции — светящиеся точки, линия «день/ночь».
- **Слева** — панель «Поиск / Избранное / Фильтры».
- **Снизу** — плеер: флаг, название станции, город, кнопки, громкость, «следующая рядом».
- **Справа** — выезжающая карточка места: время, погода, факт.

## 7. Принятые решения (03.10.2026)
1. **Фишки v1:** «📍 Карточка места» и «🗣️ Учу язык». Остальные — кандидаты на будущее.
2. **Станции:** только HTTPS. Прокси для HTTP — возможное расширение позже.
3. **Интерфейс:** в v1 только русский, но с мультиязычностью с первого дня (все тексты в файлах переводов, никаких строк в коде). Следующие языки: английский, китайский, японский, арабский (письмо справа налево — учесть в вёрстке), французский, немецкий, украинский, испанский.
4. **Название:** «Радио планеты» — рабочее, может поменяться. Поэтому в коде и домене к нему не привязываемся.
5. **Роли:** Claude — идеи, советы, ТЗ. Код пишет отдельный агент-программист.
6. **Отображение мира:** 3D-глобус и плоская карта с переключателем.
7. **Хостинг:** выбирает программист (GitHub Pages или Cloudflare Pages).
8. **База v1:** поиск, избранное, «Удиви меня», «Поделиться станцией», таймер сна, установка на телефон (PWA).
9. **Карточка места:** флаг и язык страны, факт о городе, местное время. Погоду в v1 не показываем.
