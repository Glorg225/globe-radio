## 1. Цель
Сделать бесплатный веб-сервис: пользователь видит мир (3D-глобус или плоская карта), на нём точки радиостанций. Клик по точке включает живой эфир и показывает карточку места. Режим «Учу язык» оставляет только станции на выбранном языке.

**Ограничения проекта:**
- **$0 на инфраструктуру.** Только статический хостинг и бесплатные открытые API.
- **Нет собственного сервера и базы данных.** Допускается только автоматизация сборки (например, GitHub Actions).
- **Без регистрации пользователей.** Всё личное (избранное, настройки) хранится в браузере.

## 3. Пользовательские сценарии
1. **Открыл и слушаю.** Захожу на сайт → вижу глобус со светящимися точками → кручу → кликаю по городу → вижу список станций → нажимаю на станцию → играет эфир, справа (на телефоне — снизу) открывается карточка места.
2. **Учу испанский.** Включаю «Учу язык» → выбираю «Испанский» → на глобусе остаются только станции на испанском → кликаю «Удиви меня» → играет случайная испаноязычная станция.
3. **Делюсь с другом.** Нажимаю «Поделиться» → ссылка копируется (на телефоне — системное меню «Поделиться») → друг открывает ссылку → сайт сразу открыт на этой станции, глобус повёрнут к её городу. Автозапуск звука браузеры блокируют, поэтому другу показывается большая кнопка ▶.
4. **Засыпаю под радио.** Ставлю таймер на 30 минут → через 30 минут звук плавно затухает и плеер останавливается.
5. **Мои станции.** Добавляю станцию в избранное ★ → после перезапуска браузера она на месте.

## 4. Функциональные требования

### 4.1 Отображение мира
- **Два режима:** 3D-глобус (по умолчанию на ПК) и плоская карта (по умолчанию на слабых и мобильных устройствах или по выбору). Переключатель всегда виден, выбор запоминается.
- Тёмная «космическая» тема строго по утверждённому макету (раздел 11). Земля ночью, точки станций светятся.
- **Тысячи точек.** Станции группируются (кластеры) по городу и при отдалении. При приближении кластеры раскрываются.
- Яркость или размер точки зависят от популярности (поля `votes` / `clickcount`).
- **Наведение** (ПК): подсказка «Город, страна — N станций». **Клик**: панель со списком станций этого места, отсортированных по популярности.
- Станция, которая сейчас играет, выделена на карте (пульсирующая точка).
- **Производительность:** 60 к/с на среднем ПК; на телефоне без подвисаний при вращении. Если 3D не тянет (нет WebGL или низкий FPS) — автоматически переключаемся на плоскую карту и показываем уведомление.

### 4.2 Плеер
- Play/Pause, громкость, Mute, название станции, город, страна, иконка станции. Если иконка не грузится — заглушка с первой буквой названия.
- Кнопка «Следующая рядом» — ближайшая станция с учётом активного фильтра языка.
- Поддержка обычных потоков (MP3/AAC) и HLS (`.m3u8`).
- **Ошибки:** если поток не стартовал за 8 с или оборвался — сообщение «Станция не отвечает» и кнопка «Попробовать следующую рядом». Нерабочую станцию запоминаем в браузере на 24 ч и не предлагаем в «Удиви меня».
- Media Session API: название и кнопки на экране блокировки телефона и в системных уведомлениях.
- Только станции с HTTPS-потоком. Станции с HTTP-потоком не показываются вообще.

### 4.3 Карточка места
Открывается при запуске станции, её можно свернуть.
| Поле | Источник | Если данных нет |
|---|---|---|
| Флаг страны | Код страны станции → SVG-флаг (**не эмодзи**: на Windows эмодзи-флаги показываются буквами) | Скрыть |
| Страна и город | Поля станции; город — по координатам (ближайшая статья Википедии или справочник городов) | Только страна |
| Язык вещания | Поле языка станции, переведённое на язык интерфейса | «Язык не указан» |
| Местное время | Часовой пояс по координатам (вычисляется в браузере, часы идут вживую) | Время по стране, если у неё один пояс; иначе скрыть |
| Факт о городе | Википедия: краткое описание + фото по названию или координатам. Сначала на языке интерфейса, если статьи нет — английская версия с пометкой | «Подробнее в Википедии» со ссылкой; если ничего не нашлось — скрыть блок |

- Ссылка «Читать в Википедии» обязательна (лицензия текста требует указания источника).
- Ответы Википедии кешировать в браузере, чтобы не запрашивать повторно.

### 4.4 Режим «Учу язык»
- Переключатель и выпадающий список языков. Языки отсортированы по количеству станций, рядом с языком — число станций.
- **В режиме:** на карте ярко только станции на выбранном языке, остальные приглушены; «Удиви меня» и «Следующая рядом» выбирают только из них; кнопка в шапке меняется на «Учу язык: испанский ▾»; под шапкой бирюзовая плашка «Режим „Учу язык“ · Испанский · N станций в N странах · Выключить». Кнопка плеера называется «Следующая на испанском».
- В карточке места у языка эфира есть ссылка «Учить этот язык» — включает режим с этим языком.
- **Данные о языках «грязные»:** поле свободное, бывают опечатки и разные написания. Нужно нормализовать к кодам ISO 639 (использовать поле кодов языков, а где его нет — словарь соответствий названий). Нераспознанные языки не показывать в списке.
- Подсказка в режиме (простой текст): «Совет: выбирайте разговорные и новостные станции — там больше речи, чем музыки». Если у станции есть теги `news` / `talk`, помечать её бирюзовой меткой с иконкой и словом «речь» (как в макете; эмодзи в интерфейсе не используем).

### 4.5 Поиск
- Одна строка поиска по названию станции, городу, стране. Подсказки при вводе (от 2 символов), поиск без учёта регистра.
- Результат: список, клик → глобус поворачивается к станции и включает её.

### 4.6 Избранное и история
- ★ у каждой станции. Отдельная вкладка «Избранное».
- История — последние 20 станций.
- Хранение в localStorage. Если оно недоступно (приватный режим) — работаем без сохранения, без ошибок.

### 4.7 «Удиви меня»
Случайная **рабочая** HTTPS-станция с учётом активного языкового фильтра. С небольшим приоритетом популярных станций, чтобы реже попадались мёртвые. Глобус красиво «летит» к ней.

### 4.8 «Поделиться»
- Ссылка вида `…/?station=<stationuuid>`. При открытии: найти станцию, повернуть к ней карту, показать кнопку ▶.
- На телефонах — системное меню «Поделиться» (Web Share API), на ПК — копирование в буфер с уведомлением «Ссылка скопирована».
- Метатеги для красивого превью ссылки в мессенджерах (общая картинка проекта).

### 4.9 Таймер сна
Варианты: 15 / 30 / 60 / 90 минут и «Выкл». Плавное затухание за последние 10 с. Оставшееся время видно в плеере.

### 4.10 PWA
- Установка на домашний экран (manifest, иконки, тема).
- Фоновое воспроизведение при свёрнутом браузере или заблокированном экране, насколько позволяет платформа (на iOS есть ограничения — задокументировать).
- Без интернета показывать экран «Нет подключения» (офлайн-радио невозможно).

## 5. Данные

### 5.1 Radio Browser API (основной источник)
- **Документация:** https://docs.radio-browser.info/
- **Серверов несколько.** Список брать через `all.api.radio-browser.info`, выбирать случайный, при ошибке переключаться на другой. API работает «без гарантий».
- Указывать название приложения там, где это возможно (параметр или заголовок), — так просят авторы API.
- **Фильтры:** только рабочие станции (`lastcheckok = 1`), только HTTPS (`url_resolved` начинается с `https://`). Станции без координат ставить в центр страны (справочник центроидов стран) с пометкой «примерное расположение».
- **Клик по станции:** вызывать эндпоинт учёта кликов (`/json/url/{stationuuid}`). Это правило API, и так станция попадает в статистику популярности.

### 5.2 Как загружать станции (рекомендация, финальное решение за программистом)
**Предпочтительно — ежедневный снимок.** GitHub Actions раз в сутки скачивает станции, фильтрует их, оставляет только нужные поля (uuid, название, координаты, страна, коды языков, теги, популярность, иконка, URL, флаг HLS) и кладёт компактный сжатый JSON в сайт. Плюсы: сайт открывается быстро, API не нагружается, работа не зависит от простоев API.

Альтернатива — запрос к API при открытии сайта с кешированием в браузере.

В любом случае **URL потока перед воспроизведением брать свежий** (через эндпоинт клика), потому что адреса меняются.

### 5.3 Другие источники
| Что | Источник | Ключ |
|---|---|---|
| Факт о городе | Wikipedia REST API (summary), MediaWiki geosearch | Не нужен |
| Часовой пояс | Офлайн-библиотека «координаты → часовой пояс» в браузере | — |
| Флаги | Открытый набор SVG-флагов (например, flag-icons, лицензия MIT) | — |
| Названия стран и языков на языке интерфейса | Встроенный в браузер `Intl.DisplayNames` | — |

## 6. Мультиязычность (закладываем сразу)
- **Ни одной строки интерфейса в коде.** Все тексты — в файлах переводов (`locales/ru.json` и т. д.) с ключами.
- **v1:** только `ru`. Архитектура готова к `en`, `zh`, `ja`, `ar`, `fr`, `de`, `uk`, `es`.
- Язык выбирается по: ссылке (`?lang=`) → сохранённому выбору → языку браузера → `ru` по умолчанию. Переключатель языка в интерфейсе появится, когда будет больше одного языка.
- **Арабский пишется справа налево (RTL).** Вёрстка на логических CSS-свойствах (`margin-inline-start` вместо `margin-left`), атрибут `dir="rtl"`. Проверить на тестовой псевдолокали.
- **Шрифты** должны поддерживать кириллицу, CJK (китайский, японский) и арабский, либо использовать системные шрифты.
- Даты, время, числа — через `Intl`. Множественное число («1 станция / 2 станции / 5 станций») — через `Intl.PluralRules`.
- Названия стран и языков не переводить вручную, а брать из `Intl.DisplayNames`.

## 7. Нефункциональные требования
- **Хостинг:** GitHub Pages или Cloudflare Pages — выбор за программистом, обосновать в README. HTTPS обязателен.
- **Скорость:** первый показ глобуса меньше чем за 3 с на среднем мобильном интернете; тяжёлые библиотеки (3D) грузить лениво.
- **Адаптивность:** телефоны от 360 px по ширине, планшеты, ПК. Без горизонтальной прокрутки. Управление пальцами: вращение, зум.
- **Доступность:** работа с клавиатуры (Tab, Space — play/pause), подписи у кнопок, достаточный контраст.
- **Браузеры:** последние Chrome, Edge, Firefox, Safari (включая iOS Safari).
- **Приватность:** без трекеров и рекламы. Если нужна аналитика — только без cookies (например, Cloudflare Web Analytics), и это согласовать с заказчиком.
- **Название проекта** хранить в одном конфиге, чтобы его можно было сменить в одном месте.
- **Внизу страницы:** «Данные о станциях — Radio Browser», «Тексты — Википедия (CC BY-SA)», дисклеймер «Мы не храним и не ретранслируем эфир, станции вещают со своих серверов».

## 8. Рекомендации по технологиям (не жёсткие)
- Одностраничное приложение без бэкенда, сборщик Vite, TypeScript.
- **3D-глобус:** globe.gl (на three.js) или аналог. **Плоская карта:** MapLibre GL или Leaflet с бесплатной тёмной подложкой (проверить условия бесплатного использования тайлов!).
- **HLS:** hls.js (в Safari — нативно).
- **i18n:** лёгкая библиотека или свой небольшой модуль на JSON и `Intl`.
- Любой выбор фреймворка обосновать кратко в README.

## 9. Рекомендуемая структура проекта
```
src/
  app/          — точка входа, роутинг по параметрам ссылки
  map/          — globe3d, map2d, общий интерфейс «карты»
  player/       — плеер, HLS, Media Session, таймер сна
  data/         — загрузка станций, фильтры, нормализация языков
  place-card/   — карточка места (Википедия, время, флаг)
  features/     — поиск, избранное, история, «Удиви меня», «Учу язык», «Поделиться»
  i18n/         — модуль локализации
  ui/           — общие компоненты, тема
locales/        — ru.json (+ будущие языки)
scripts/        — скрипт ежедневного снимка станций
public/         — иконки, manifest, превью для соцсетей
```

## 10. Этапы и критерии приёмки
| Этап | Результат | Как проверяем |
|---|---|---|
| **1. Каркас** | Сайт открывается по HTTPS-адресу, тёмная тема, i18n-модуль, `ru.json` | Ссылка работает; в коде нет строк интерфейса |

| **6. Удобства** | Поиск, избранное, история, «Поделиться», таймер сна | Ссылка из «Поделиться» в другом браузере открывает ту же станцию |
| **7. PWA и полировка** | Установка на телефон, фон, экран блокировки, адаптивность, доступность | Установка на Android и iOS; Lighthouse ≥ 90 по производительности и доступности на ПК |
| **8. Сдача** | README: как запустить, как обновить снимок, как добавить язык, что выбрано и почему | Заказчик по README может сам выложить обновление |

## 12. Риски
- **Radio Browser недоступен** → снимок станций плюс несколько зеркал API.
- **Многие станции мертвы или медленные** → фильтр `lastcheckok`, тайм-аут, «следующая рядом», локальный чёрный список.
