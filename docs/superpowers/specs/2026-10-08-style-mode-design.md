# Режим «стиль» в приложении — дизайн

*08.10.2026 · Задача #40 · Утверждено владельцем в чате 08.10.2026. Основа — словарь стилей (#32) и режим «Учу язык» (План 4), по образцу которого сделан режим.*

## 1. Поведение
- Пользователь выбирает стиль (Jazz, News, 80s…). Глобус и плоская карта подсвечивают только точки, где есть станции этого стиля (тот же слой, что у «Учу язык»; число в окошке — станции стиля). Список места показывает только станции стиля; «Следующая рядом» и «Удиви меня» выбирают только из них.
- Сверху плашка «Style · Jazz · N stations in M countries · Turn off». Выбор запоминается в браузере (`styleId`); если стиля больше нет в данных — режим сбрасывается.
- Режимы «стиль» и «Учу язык» взаимно выключают друг друга.
- В списке места без станций стиля: «No Jazz stations here» + «Show all stations of this place» (как у языка).
- Строки станций в приложении показывают стили из словаря («Jazz · Pop»), а если стиля нет — первые теги, как раньше.

## 2. Вход
- ПК: кнопка «Style» в шапке рядом с «Learn a language»; по нажатию — окно со стилями тремя группами (Genres, Formats, Decades) и числом станций. Активный режим подсвечивает кнопку.
- Блок «Browse by country» (панель без выбора и пустой поиск — на телефоне это вкладка Search) получает строку «Listen by style»: 8 крупнейших стилей кнопками, нажатие включает режим.

## 3. Данные
- `public/data/styles.json` `{ v: 1, styles: { <styleId>: [[placeId, count], …] } }` — собирается снимком из тех же подсчётов, что и стили точек (#38). Загружается при первом включении режима или открытии окна стилей; первая загрузка сайта не растёт.
- Резервный снимок (`scripts/fetch-deployed-snapshot.ts`) восстанавливает также `search.json` (раньше не восстанавливал — поиск ломался) и `styles.json` (если на сайте его ещё нет — пропускает).

## 4. Проверка
Тесты: состояние стиля (запоминание, сброс неизвестного), загрузка `styles.json`, слой карты и фильтры «Следующая»/«Удиви меня»/списка по стилю, взаимное выключение с языком, плашка, окно выбора, чипы стилей, строки станций, резервный снимок. Затем снимок + сборка + проверка в браузере (ПК и 375 px). Code-review до и после вливания.

## 5. Не входит
Сочетание стиля и языка одновременно; отдельные адреса для режима в приложении (страницы стилей для Google уже есть — `/radio/genre/`).
