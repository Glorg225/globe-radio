# План 5: поиск, избранное, история, «Удиви меня», «Поделиться», таймер сна — дизайн

*05.10.2026 · Этап 6 ТЗ (`docs/02_tz.md` §4.5–4.9) · Дизайн — `docs/03_design.md` §6.1, §6.4, `design/mockups/Main.dc.html`, `design/mockups/MobileShare.dc.html` · Основа — Планы 1–4 (в `main`).*

## 1. Цель и критерии готовности
Удобства вокруг глобуса: найти станцию или место, сохранить любимые, вернуться к недавним, послушать случайную станцию, поделиться ссылкой и заснуть под радио.

**Готово, когда:**
- Ссылка из «Поделиться», открытая в другом браузере, показывает ту же станцию (карточка «Вам прислали станцию» → «Слушать» → играет она).
- Поиск находит станцию по части названия и место по городу/стране; клик включает станцию / открывает место.
- Избранное и история переживают перезагрузку; в приватном режиме — без ошибок.
- «Удиви меня» в режиме «Учу язык» включает только станции этого языка (10 нажатий подряд).
- Таймер сна 15 мин: звук плавно затухает и эфир останавливается вовремя.
- Первая загрузка сайта не растёт (индекс поиска грузится при первом обращении к поиску).

## 2. Решения заказчика (05.10.2026)
1. Поиск — по собственному индексу `search.json` (≈ 400 КБ gzip), который загружается при первом клике в поле поиска.
2. Ссылка «Поделиться» — `?station=<id>&c=<код страны>`; без `c` страна берётся у Radio Browser.
3. В режиме «Учу язык» поиск ищет по всем станциям; «Удиви меня» — только по языку.
4. Плашка «Установить на главный экран» и вкладка «Поиск» на телефоне — План 6.

## 3. Поиск
- **Данные:** снимок пишет `public/data/search.json`: `{ v: 1, stations: [name, placeId][] }`, отсортировано по популярности (клики) по убыванию. Места берутся из уже загруженного `places.json`.
- **Сравнение:** строка и названия приводятся к нижнему регистру без диакритики; совпадение — вхождение подстроки; начало названия/слова ранжируется выше.
- **Выдача** (с 2 символов, задержка ~150 мс): раздел «Места» — до 5 (русское и местное название, название страны), раздел «Станции» — до 8 (с подписью места). Пусто — «Ничего не найдено».
- **Клик по месту** — перелёт к месту и его список. **Клик по станции** — перелёт, список места, станция играет (станция берётся из файла страны по названию и месту).
- Клавиатура: стрелки, Enter, Esc; клик вне — закрыть. Пока индекс грузится — «Загружаем станции…»; ошибка загрузки — «Не удалось загрузить поиск» с повтором при следующем вводе.

## 4. Избранное и история
- Запись в браузере: `{ id, name, placeId, cc, favicon }` — вкладки рисуются без загрузки файлов стран.
- **Избранное** (`favorites`): звезда в строке списка и в плеере (обе активны); новые сверху; без лимита.
- **История** (`history`): последние 20 сыгранных, новые сверху, без повторов.
- **Вкладки** «Здесь / Избранное / История» переключают левую панель; «Здесь» — список выбранного места (как раньше).
- Включение из вкладки: загрузить файл страны, найти станцию по `id`; нет — уведомление «Станция больше не вещает».
- Хранилище недоступно — всё работает в пределах сессии.

## 5. «Удиви меня»
1. Место — случайно с весом по числу станций (в режиме языка — по числу станций языка).
2. Станция места — случайно с весом `log(клики + 2)`; пропускаются чёрный список и недавно сыгранные; если в месте подходящих нет — до 5 попыток с другим местом.
3. Перелёт к месту, список места, станция играет. Нет ни одной подходящей — уведомление «Не удалось найти станцию, попробуйте ещё раз».

## 6. «Поделиться»
- Кнопка в плеере (активна, когда есть станция). Есть `navigator.share` → системное меню (заголовок — название станции, текст «Слушаю «<станция>» — <место>», ссылка); иначе — копирование в буфер и уведомление «Ссылка скопирована»; ошибка копирования — уведомление «Не удалось скопировать ссылку».
- **Открытие ссылки** (`?station=…`): после загрузки мест найти станцию (файл страны `c` или страна через Radio Browser `/json/stations/byuuid/<id>`), повернуть карту к месту, приглушить карту и показать карточку по макету `MobileShare`: «ВАМ ПРИСЛАЛИ СТАНЦИЮ», иконка 72, название, флаг + «Город, Страна · местное время», кнопка «▶ Слушать» (высота 56, во всю ширину), пояснение «Браузер включает звук только после нажатия — поэтому нужна эта кнопка.», ссылка «Открыть глобус». «Слушать» — станция играет, карточка закрывается; «Открыть глобус» — карточка закрывается без звука. Параметр убирается из адреса (`history.replaceState`).
- Станция не найдена → уведомление «Станция из ссылки больше не вещает», обычный вид.
- **Превью:** метатеги `og:title`, `og:description`, `og:image` (1200×630, `public/og.png`), `twitter:card=summary_large_image`. Картинка собирается один раз скриптом из SVG (тёмный фон, янтарный логотип, «Радио планеты», подзаголовок) и хранится в проекте.

## 7. Таймер сна
- Кнопка «Сон» в плеере → меню: 15 / 30 / 60 / 90 мин, «Выкл» (текущий отмечен).
- Идёт таймер → на кнопке «Сон · 23 мин» (обновление раз в минуту).
- Последние 10 с — громкость плавно до 0, затем пауза; громкость возвращается к прежней; таймер выключается.
- Ручная пауза/смена станции таймер не сбрасывают; «Выкл» — отменяет. Не запоминается между перезагрузками.

## 9. Проверка
**Автотесты:** нормализация и ранжирование поиска, загрузка индекса (один раз, повтор после ошибки), выдача и клавиатура; избранное (добавить/убрать/порядок/хранилище недоступно), история (20, без повторов); «Удиви меня» (веса, язык, чёрный список, недавние, нет кандидатов); разбор и сборка ссылки, открытие ссылки (найдена / нет `c` / не найдена), Web Share vs буфер; таймер (оставшееся время, затухание, выключение, восстановление громкости); вкладки панели.
**Вручную:** ссылка в другом браузере; поиск станции и места; избранное после перезагрузки; 10 × «Удиви меня» в режиме «Испанский»; таймер (ускоренно — в консоли).
