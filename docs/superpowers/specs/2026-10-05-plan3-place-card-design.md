# План 3: карточка места — дизайн

*05.10.2026 · Этап 4 ТЗ (`docs/02_tz.md` §4.3) · Дизайн — `docs/03_design.md` §6.1 (правая панель), §6.3 (телефон), `design/mockups/Main.dc.html`, `design/mockups/MobilePlayer.dc.html` · Основа — Планы 1–2.*

## 1. Цель и критерии готовности
Пока играет станция, рядом видна карточка её места: флаг, место и страна, живое местное время, язык эфира и короткий факт из Википедии с фото и ссылкой.

**Готово, когда:**
- 10 разных станций (города, регионы, «страна»): местное время совпадает с реальным, у мест со статьёй есть ссылка «Читать в Википедии».
- Карточка ПК 1440×900 совпадает с макетом бок о бок; на телефоне 390×844 — шторка снизу.
- Первая загрузка сайта не растёт (данные карточки — в файлах стран, которые и так грузятся по клику).

## 2. Решения заказчика (05.10.2026)
1. Для станций без города (место вида «страна») — **карточка страны**: флаг, страна, язык, статья Википедии о стране; время — только если у страны один часовой пояс.
2. Подготовка данных заранее, при ежедневной выгрузке (не в браузере).

## 3. Данные
### 3.1 Справочник (дополнение к Плану 2)
`scripts/build-gazetteer.ts` дополнительно сохраняет для городов и регионов:
- **часовой пояс** города (столбец `timezone` в `cities15000`; у региона — пояс его самого населённого города);
- **название статьи английской Википедии** и, если есть, **русской** — из записей `link` в `alternateNamesV2` (`https://en.wikipedia.org/wiki/<title>`, `https://ru.wikipedia.org/wiki/<title>`), раскодированное.

### 3.2 Снимок
Файл страны `stations/<CC>.json` получает поле `places`: для каждого места этой страны — `[id, tz, wikiRu, wikiEn]` (пустая строка, если нет).
- Место-город / точка у города: пояс и статьи города.
- Место-регион: пояс центра региона, статьи региона.
- Место-страна: пояс — единственный пояс всех городов страны в справочнике, иначе пусто; статьи — русское название страны (`Intl.DisplayNames(['ru'])`) как `wikiRu`, английское — как `wikiEn`.
- `places.json` не меняется. Версия файлов стран остаётся `v: 2` с новым необязательным полем (старые файлы без `places` → карточка без времени и Википедии).

## 4. Карточка
### 4.1 Когда и чья
- Карточка показывает место **играющей** станции (состояния «подключаемся», «в эфире», «пауза», «не отвечает»). Листание списков других мест её не меняет.
- Ничего не играет → заглушка «Карточка места появится, когда начнёт играть станция».
- Кнопка-шеврон сворачивает правую панель (центр шире); состояние запоминается.

### 4.2 Содержимое (по макету, `03_design.md` §6.1)
1. Надпись «КАРТОЧКА МЕСТА» + кнопка «Свернуть».
2. **Флаг** 54×36 (набор flag-icons, MIT; грузится только флаг нужной страны) + заголовок (Unbounded 24) + подзаголовок:
   - город/точка — название места, подзаголовок — страна;
   - регион — название региона, подзаголовок — страна;
   - страна — название страны, подзаголовок — «Примерное расположение станций».
   Флаг не загрузился или его нет → блок флага скрыт.
3. Две плитки:
   - **«Местное время»** — часы (Unbounded 28), обновляются каждую минуту ровно на смене минуты; подпись «на N ч раньше вас» / «на N ч позже вас» / «как у вас» (дробные пояса — «на 5 ч 30 мин позже вас»). Пояс неизвестен → плитка скрыта.
   - **«Язык эфира»** — названия языков станции через `Intl.DisplayNames` на языке интерфейса, со строчной буквы, через запятую; нет языков — «Язык не указан». Под ним кнопка «Учить этот язык» — **неактивна** до Плана 4 (подсказка «Появится скоро»).
4. **Википедия**:
   - порядок поиска: `wikiRu` → русская статья через межъязыковые ссылки английской (`wikiEn`) → английская статья с пометкой «Статья на английском» → ничего;
   - показываем: фото (высота 150 px, `object-fit: cover`), начало статьи (до 3 предложений, не больше ~320 символов), ссылку «Читать в Википедии ↗» (новая вкладка);
   - статья есть, но текста нет (ошибка сети) → только ссылка «Подробнее в Википедии ↗»;
   - ничего не нашлось → блок скрыт.
   - Источники: Wikipedia REST `page/summary/<title>` и `w/api.php?action=query&prop=langlinks` (без ключа, `origin=*`).

### 4.3 Телефон
Шторка снизу над мини-плеером (по `03_design.md` §6.3): ручка, флаг, место, «страна · язык», время справа, 2 строки факта, «Подробнее в Википедии». Не видна, пока открыт список станций. Точная мобильная вёрстка — План 6.

## 5. Ошибки и крайние случаи
- Википедия недоступна / ошибка → только ссылка (если название статьи известно); флаг, время, язык работают без сети; ошибки не кешируются.
- Быстрая смена станции → ответ для прошлого места отбрасывается (номер запроса, как в плеере).
- Фото не загрузилось → скрыто.
- Неизвестный пояс → плитка времени скрыта.
- Хранилище недоступно → без кеша, без ошибок.
- Тексты Википедии — только через `textContent`; ссылки строятся из названия статьи (`encodeURIComponent`), не из ответа.
- Кеш ответов Википедии в `localStorage` на 30 дней (ключ — язык + название статьи), с ограничением ~200 записей (старые удаляются).

## 6. Модули и файлы (ориентир для плана)
```
scripts/build-gazetteer.ts (+ tz, wiki), scripts/build-snapshot.ts (+ places в файлах стран), data/gazetteer.json (пересборка)
src/data/shards.ts            — чтение поля places → PlaceInfo
src/place-card/time.ts        — часы, разница с пользователем
src/place-card/language.ts    — названия языков
src/place-card/wiki.ts        — поиск статьи, кеш, отбрасывание устаревших
src/place-card/flag.ts        — URL флага по коду страны
src/place-card/place-card.ts  — разметка карточки (ПК и телефон), сворачивание
src/app/app.ts                — показ карточки при смене играющей станции
locales/ru.json               — новые строки
```

## 7. Проверка
**Автотесты:** пояс места (город, регион, страна с одним и несколькими поясами), подпись разницы во времени (раньше/позже/как у вас/дробная), названия языков, порядок поиска статьи (ru → langlinks → en → нет), кеш (30 дней, недоступное хранилище, лимит), отбрасывание устаревшего ответа, разметка карточки (экранирование, скрытие блоков, неактивная кнопка «Учить этот язык»), сворачивание и его запоминание, заглушка без станции.
**Вручную:** 10 разных станций — время и ссылка; сравнение с макетом 1440×900 и 390×844.
