# План 4: режим «Учу язык» — дизайн

*05.10.2026 · Этап 5 ТЗ (`docs/02_tz.md` §4.4) · Дизайн — `docs/03_design.md` §1 (бирюзовые токены), §6.2, `design/mockups/Language.dc.html` · Основа — Планы 1–3.*

## 1. Цель и критерии готовности
Пользователь выбирает язык — карта подсвечивает места со станциями на этом языке, список и «Следующая на …» выбирают только из них, карточка места помогает включить режим с языком текущей станции.

**Готово, когда:**
- Выбран «Испанский» → все станции, которые включает «Следующая на испанском», испаноязычные (≥ 10 нажатий подряд); список места показывает только испанские станции.
- Экран ПК 1440×900 совпадает с макетом «Учу язык» бок о бок (кнопка, выпадающий список, плашка, совет, метка «речь», плитка языка в карточке, кнопка плеера).
- Первая загрузка выросла не больше чем на ~20 КБ (gzip).

## 2. Решения заказчика (05.10.2026)
1. Нажатие на приглушённое место (нет станций на выбранном языке) → сообщение «Здесь нет станций на испанском» и кнопка «Показать все станции этого места»; режим не выключается.
2. Данные о языках мест — в `places.json` (+~13 КБ gzip), чтобы карта перекрашивалась мгновенно.
3. Выбранный язык запоминается в браузере; ссылка `?learn=` — не в этом плане.
4. «Удиви меня» появится в Плане 5 и будет учитывать язык; в плашке пока упоминается только «Следующая рядом».

## 3. Данные
- В запись места в `places.json` добавляется 10-е поле — счётчики языков станций места: строка `"es:12,ca:3"` (пусто, если языков нет). Версия файла остаётся `v: 2`; старый файл без поля → у мест нет языков (режим просто ничего не подсвечивает).
- В клиенте `Place.langs: Record<string, number>`.
- Индекс языков (считается в браузере из мест): код, название на языке интерфейса (`Intl.DisplayNames`), число станций, число стран; сортировка по числу станций. Языки без названия в `Intl` не показываются.

## 4. Поведение
### 4.1 Выбор языка (шапка)
- Кнопка «Учу язык» (контурная) открывает выпадающий список по макету: поле «Найти язык», строки «Испанский · 5 081 станция», выбранный подсвечен (`--teal-chip-bg`, текст `--teal`).
- Поиск — без учёта регистра по названию и по коду (`es`); пусто → «Ничего не найдено».
- Закрытие: Esc, клик вне списка, выбор языка. Клавиатура: стрелки вверх/вниз, Enter. `aria-expanded` у кнопки.
- Выбор языка → режим включён; выбор того же языка ещё раз → режим выключен.
- В режиме кнопка бирюзовая: «Учу язык: испанский ▾».

### 4.2 Плашка под шапкой
Высота 48 px, `--teal-banner-bg` / `--teal-banner-border`: иконка, **«Режим „Учу язык“»**, «Испанский · 5 081 станция в 66 странах · „Следующая рядом“ выбирает только из них», кнопка «Выключить».

### 4.3 Карта
- Два слоя: все места — приглушённые (`--dot-muted`, прозрачность 35 %, без свечения), сверху места языка — бирюзовые (`--teal`, свечение), размер/яркость по числу станций языка.
- Группировка бирюзового слоя считает только станции языка; подсказка: «Мадрид · 12 станций на испанском».
- Глобус и плоская карта — одинаково. Пульс играющей станции остаётся янтарным.

### 4.4 Список станций
- Место со станциями языка: подзаголовок «Испания · 12 станций на испанском»; бирюзовый блок «Совет: выбирайте разговорные и новостные станции — там больше живой речи, чем музыки.»; только станции языка; плитка-буква бирюзовая (`--teal-tile`, буква `--teal`); у станций с тегом `news` или `talk` — метка «речь» с иконкой (`--teal-chip-bg`, `--teal`).
- Место без станций языка: «Здесь нет станций на испанском» + кнопка «Показать все станции этого места» (обычный список этого места, режим остаётся).

### 4.5 Плеер
- Кнопка «Следующая на испанском» — ближайшая станция только на выбранном языке; никого → уведомление «Рядом больше нет станций на испанском».
- Включение/выключение режима не останавливает эфир.

### 4.6 Карточка места
- Язык станции совпадает с выбранным → плитка «Язык эфира» бирюзовая (`--teal-tip-bg`), подпись «совпадает с выбранным», кнопки нет.
- Иначе кнопка «Учить этот язык» активна: включает режим с первым распознанным языком станции. Нет распознанного языка → кнопки нет.

### 4.7 Склонение названий языков
Фразы «на испанском», «в 66 странах» требуют русских падежей. Предложный падеж названия языка: окончание «-ий/-ый/-ой» → «-ом» (испанский → испанском), «-ь» → «-и» (латынь → латыни), согласная → «+е» (иврит → иврите), гласная — без изменений (хинди, суахили). Правило живёт в модуле русской грамматики; для будущих языков интерфейса — свои правила или нейтральная формулировка.

### 4.8 Запоминание и ошибки
- Язык хранится в `localStorage`; при загрузке восстанавливается, если такой язык есть в данных, иначе молча сбрасывается.
- Хранилище недоступно → всё работает без запоминания.

## 6. Проверка
**Автотесты:** счётчики языков мест (снимок и чтение), индекс (сортировка, страны, поиск по названию и коду, пустой результат), падежи (испанский/латынь/иврит/хинди), состояние (включить/выключить/повторный выбор/восстановление/неизвестный язык/нет хранилища), список (фильтр, совет, «речь», пустое место с кнопкой «показать все»), «Следующая на …» только по языку, карточка (бирюзовая плитка, кнопка включает режим), выпадающий список (клавиатура, Esc, клик вне), слои карты (приглушённые и бирюзовые элементы).
**Вручную:** «Испанский» → 10 раз «Следующая на испанском», все испанские; сравнение с макетом 1440×900; телефон 390×844 (плашка и список языков без горизонтальной прокрутки).

## 7. Не входит в План 4
«Удиви меня» (План 5, будет учитывать язык); ссылка `?learn=`; фильтр по жанрам (следующий этап, компонент фильтра делается переиспользуемым).
