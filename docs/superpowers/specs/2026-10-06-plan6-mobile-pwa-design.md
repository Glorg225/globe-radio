# План 6: телефон, установка (PWA), доводка, сдача — дизайн

*06.10.2026 · Этапы 7–8 ТЗ (`docs/02_tz.md` §4.10, §7, §10) · Дизайн — `docs/03_design.md` §6.3, §6.4, `design/mockups/MobilePlayer.dc.html`, `design/mockups/MobileShare.dc.html` · Основа — Планы 1–5 (в `main`).*

## 1. Цель и критерии готовности
Сайт удобен на телефоне, ставится на главный экран, честно ведёт себя без интернета, доведён по доступности и сдаётся с README, по которому заказчик сам выкладывает обновления.

**Готово, когда:**
- Телефон 390×844 совпадает с макетом `MobilePlayer` бок о бок; ширина 360 — без горизонтальной прокрутки.
- Android: сайт ставится на главный экран (Chrome «Установить»), открывается без адресной строки, эфир играет при выключенном экране, на экране блокировки — название, место, кнопки (проверяет заказчик на своём Android).
- iPhone: в эмуляции — вёрстка и подсказка «Поделиться → На экран Домой»; ограничения описаны в README.
- Без интернета: оболочка открывается из памяти, видна плашка «Нет подключения к интернету», плеер не пытается подключаться бесконечно; при возврате сети плашка исчезает.
- Lighthouse на ПК: производительность ≥ 90, доступность ≥ 90.
- Отложенные мелочи Плана 5 (раздел 6) закрыты.
- README по разделу 8.

## 3. Телефон (ширина ≤ 760 px)
Сверху вниз:
- **Шапка 60 px:** логотип + «Радио планеты» (Unbounded 16), справа «Удиви меня» 44×44 (янтарная, радиус 12). Поиск, «Учу язык», «Установить» в шапке скрыты.
- **Переключатель «3D | Карта»:** по центру, 68 px от верха, кнопки 30 px.
- **Карта** на весь экран (касания: вращение, зум — уже есть).
- **Шторка карточки места** (над мини-плеером): ручка 40×4, флаг 42×28, город (Unbounded 18), «Страна · язык» 13 px, справа местное время (Unbounded 20) + «местное время»; 2 строки факта (14 px, обрезка) + «Подробнее в Википедии». Смахивание вниз — свернуть; повторный выбор станции/места — показать.
- **Мини-плеер** плавающий: отступы 8 px, высота 68, радиус 16, фон `#1A2346`, рамка `#34407A`. Иконка 46, название 15/600, строка «В эфире · сон через N мин» 12 px; «⋯» 44×44 — меню «Таймер сна / Поделиться / В избранное (Убрать)»; Play/Pause 48 круглая янтарная.
- **Нижнее меню 66 px:** «Глобус / Поиск / Избранное / Учу язык», 4 равные колонки, активная — янтарная полоска сверху; в режиме языка у «Учу язык» бирюзовая полоска.
- **Вкладки меню:** «Глобус» — обычный вид; «Поиск» — экран во всю высоту с полем (фокус сразу) и выдачей Плана 5; «Избранное» — шторка со списками «Избранное / История»; «Учу язык» — список языков (как выпадающий на ПК), бирюзовая плашка под шапкой при выбранном языке.
- **Список станций места:** нажатие на точку — шторка списка на половину высоты (можно растянуть до полной); выбор станции — список закрывается, видна шторка карточки места.
- **Планшет (761–1100 px):** раскладка ПК; карточка места не скрыта, а открывается шторкой справа кнопкой в стадии.
- Плашка учёбы, уведомления, меню сна и карточка ссылки — с учётом нижнего меню и мини-плеера (ничего не перекрывает кнопки).
- На экране ссылки (`MobileShare`) список места не выезжает поверх карточки; карта приглушена целиком.

## 4. Установка (PWA)
- **Manifest:** `name`/`short_name` из конфига названия, `theme_color` и `background_color` `#0A0F1E`, `display: standalone`, `orientation: portrait`, `start_url` и `scope` — путь сайта (GitHub Pages: `/globe-radio/`).
- **Иконки:** 192, 512, 512 maskable, `apple-touch-icon` 180 — генерируются один раз скриптом из SVG логотипа (`@resvg/resvg-js`, как `og.png`) и хранятся в `public/icons/`.
- **Service worker** (`vite-plugin-pwa`, `registerType: 'prompt'`): precache оболочки (html, js, css, шрифты, локали, флаги, текстура Земли). `data/*.json` — `NetworkFirst` (свежие данные, при отсутствии сети — последняя копия). Потоки радио, Radio Browser, Википедия — не кешируются.
- **Новая версия:** уведомление «Доступна новая версия · Обновить» — по нажатию обновляет страницу.
- **Установка:**
  - ПК: кнопка «Установить» в шапке активна, когда браузер разрешает (`beforeinstallprompt`), иначе скрыта; после установки скрыта.
  - Android: плашка «Добавить на главный экран · Установить» внизу (над меню) на экране ссылки и на обычном экране со второго визита; крестик скрывает навсегда (`installDismissed`).
  - iPhone (Safari, не установлен): та же плашка с текстом «Нажмите «Поделиться» → «На экран Домой»», без кнопки.
- **Нет подключения:** `navigator.onLine` + события `online/offline`: плашка «Нет подключения к интернету» под шапкой; play без сети — сообщение «Нет подключения — эфир недоступен» без 8-секундного ожидания; при `online` плашка уходит.

## 5. Фоновое воспроизведение
- Android/ПК: играет при свёрнутом браузере и выключенном экране; Media Session (План 2) — название, место, play/pause/следующая.
- iPhone: фон есть, но система может остановить эфир; громкость не регулируется из страницы, поэтому затухание таймера сна не работает (эфир останавливается вовремя) — в README.

## 6. Доводка (отложенное из Плана 5)
1. Меню сна: стрелки/Home/End, Tab закрывает меню.
2. Карточка ссылки: фокус удерживается внутри (Tab по кругу), фон недоступен (`inert`).
3. Поиск: роль combobox — `aria-expanded`, `aria-controls`, `aria-activedescendant`; Tab закрывает выдачу.
4. Звезда во вкладках «Избранное/История»: фокус остаётся на той же строке после перерисовки.
5. Во вкладках подсвечивается играющая станция после «Следующей».
6. Возврат на «Здесь»: сразу «Загружаем…», старый список не кликабелен.
7. Последний выбор станции (из сохранённых, из поиска) побеждает медленный предыдущий.
8. Станция из поиска не найдена в файле страны → «Станция больше не вещает»; ошибка сети файла страны → «Не удалось загрузить список станций».
9. Ссылка без страны: тайм-аут через `AbortController` (без `AbortSignal.timeout`).
10. Enter в поиске до прихода новой выдачи не выполняет старый результат.
