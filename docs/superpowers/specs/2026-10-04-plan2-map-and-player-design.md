# План 2: глобус, плоская карта и плеер — дизайн

*04.10.2026 · Этап 3 ТЗ (`docs/02_tz.md` §4.1, §4.2, §5) · Дизайн — `docs/03_design.md`, `design/mockups/Main.dc.html` · Основа — План 1 (оболочка, i18n, снимок станций).*

## 1. Цель и критерии готовности
Пользователь видит глобус (или плоскую карту) с точками станций, наводит — видит «Место · N станций», кликает — слева список станций места, кликает станцию — играет эфир, точка пульсирует, внизу плеер по макету.

**Готово, когда:**
- 10 случайных станций из разных стран: играют ≥ 8; на мёртвой — сообщение «Станция не отвечает» и кнопка «Попробовать следующую рядом».
- Экран ПК 1440×900 совпадает с макетом бок о бок (глобус, подсказка, список, плеер).
- До появления глобуса загружается не больше ~1 МБ (gzip) своих данных и кода, не считая лениво грузящейся 3D-библиотеки и текстуры.
- На телефоне 390×844: карта, нажатие на точку, список, мини-плеер — работают (точная мобильная вёрстка — План 6).

## 2. Решения заказчика (04.10.2026)
1. **Станции без координат** (73 %) — размещать по полю региона станции (`state`) через справочник GeoNames. Только по региону, не угадывать по названию станции. Без региона — одна точка в центре страны с пометкой «примерное расположение».
2. **Чёрный список нерабочих станций — 12 часов** (в ТЗ было 24; ТЗ исправлено).
3. Технические решения — за исполнителем (ниже).

## 3. Данные: три уровня
Снимок из Плана 1 (8,8 МБ / 3,8 МБ gzip) заменяется на:

| Файл | Когда грузится | Содержимое |
|---|---|---|
| `data/places.json` | сразу | Места: id, широта, долгота, вид (`exact` / `region` / `country`), код страны, названия (`ru`, местное), число станций, суммарная популярность. Цель ≤ 300 КБ gzip |
| `data/stations/<CC>.json` | по клику на место этой страны | Станции страны (формат Плана 1 + `placeId`) |
| свежий URL потока | перед воспроизведением | `GET /json/url/{stationuuid}` у Radio Browser (заодно учёт клика, требование API) |

Формат версионирован (`v: 2`). `meta.json` остаётся (отчёт снимка + число мест, доля станций по видам размещения).

### 3.1 Как станция получает место (в скрипте снимка)
1. **Есть координаты** → ближайший город справочника в радиусе 30 км: место = этот город (координаты и название города). Дальше 30 км — место по координатам станции с названием ближайшего города.
2. **Нет координат, есть регион** → регион ищется в справочнике по стране станции: сначала среди регионов (admin1), потом среди городов. Сравнение без регистра и диакритики, без слов «region / state / province / oblast / область / край» и т. п. Найден регион → место = его самый населённый город, название — название **региона** («Бавария»). Найден город → место = город.
3. **Иначе** → место «страна» в центре страны, название — название страны (`Intl.DisplayNames`), пометка «примерное расположение».

Отчёт снимка дополняется: сколько станций размещено каждым способом, топ-30 нераспознанных регионов.

### 3.2 Справочник городов и регионов (GeoNames, CC BY 4.0)
- Отдельный скрипт `scripts/build-gazetteer.ts` один раз скачивает `cities15000`, `admin1CodesASCII`, русские альтернативные названия и пишет компактный `data/gazetteer.json` в репозиторий. Запускается вручную редко (раз в полгода); ежедневный снимок его только читает.
- Название места: русское, если есть; иначе местное/ASCII.
- Атрибуция: «Географические данные — GeoNames (CC BY 4.0)» в строке внизу экрана и README.

## 4. Карта
### 4.1 Общий интерфейс
Остальное приложение работает с картой только через интерфейс `MapView` (смонтировать, показать места, выделить играющее место, перелететь к точке, приблизить/отдалить, события «наведение» и «клик по месту»). Две реализации: **глобус 3D** и **плоская карта**. Переключатель «3D | Карта» в шапке, выбор запоминается.

### 4.2 Группировка (общая)
Места группируются при отдалении (библиотека supercluster; уровень приближения переводится из высоты камеры глобуса или масштаба карты). Группа показывает сумму станций; клик по группе приближает, клик по месту открывает список. Точка: 3–7 px, янтарная, прозрачность 45–100 % по популярности, свечение `0 0 8px`; играющее место — точка 14 px + пульсирующее кольцо (1,8 с; отключается при `prefers-reduced-motion`).

### 4.3 Глобус 3D
- **globe.gl** (на three.js), загружается лениво после показа оболочки.
- Текстура ночной Земли **NASA Black Marble** (общественное достояние), уменьшенная до ~2048×1024, в гамме макета; звёзды фона; свечение атмосферы по макету.
- Вращение мышью/пальцами, кнопки +/−, плавный перелёт 1–1,5 с.

### 4.4 Плоская карта
- Холст: контуры стран (world-atlas 110m, TopoJSON) на фоне `#0F1630`, сетка `#25305C`, экватор и нулевой меридиан `#33407A`, рамка `#26305A`, радиус 16 — по макету. Без сторонних тайлов.
- Перетаскивание и приближение мышью/пальцами (d3-zoom), те же точки, группы, подсказки, клики.

### 4.5 Автовыбор режима
- По умолчанию: ПК — глобус, телефон (узкий экран + сенсорный ввод) — карта; сохранённый выбор важнее.
- Нет WebGL или средний FPS глобуса < 30 в первые 3 с → плоская карта и уведомление «Включена плоская карта: 3D не поддерживается на этом устройстве».

## 5. Список станций (левая панель)
По макету: заголовок места (Unbounded 20), строка «Страна · N станций · по популярности» (для вида «страна» — «примерное расположение»), строки станций: плитка-буква 40×40 (или иконка станции, если загрузилась), название, теги, звезда (неактивна до Плана 5). Играющая станция — фон `--item-selected`. Сортировка по популярности. Строки — кнопки, доступны с клавиатуры. На телефоне список — выдвижная панель снизу.

## 6. Плеер
### 6.1 Запуск
Клик по станции → свежий URL через `/json/url/{uuid}` (зеркала Radio Browser с перебором; если API недоступен — URL из снимка). URL не HTTPS → ошибка. MP3/AAC — элемент `<audio>`; HLS (`hls` у станции или `.m3u8`) — hls.js, загружается лениво; в Safari — нативно.

### 6.2 Панель плеера (ПК, по макету)
Слева иконка 56, название, «● В эфире · Место, Страна», звезда (неактивна); по центру Play/Pause 56 и «Следующая рядом»; справа «Сон», «Поделиться» (неактивны до Плана 5) и громкость (иконка + ползунок 120 px). Громкость и mute запоминаются. Пробел — пауза/продолжить, если фокус не в поле ввода. Media Session: название, место, иконка; кнопки «пауза» и «следующая» на экране блокировки.

### 6.3 «Следующая рядом»
Ближайшая по расстоянию станция, кроме текущей и станций из чёрного списка: сначала в текущем месте, потом в ближайших местах по `places.json`; если нужна станция другой страны — подгрузить её файл. Задел на План 4: функция принимает фильтр станций (язык).

### 6.4 Ошибки
- Поток не начал играть за **8 с** или оборвался (ошибка или «заикание» дольше 8 с) → в плеере «Станция не отвечает» + кнопка «Попробовать следующую рядом». Станция — в **чёрный список на 12 ч** (localStorage); такие станции не предлагаются в «Следующая рядом» (и в «Удиви меня» в Плане 5).
- Не загрузился файл страны → в панели «Не удалось загрузить станции этого места» + «Повторить».
- Хранилище браузера недоступно → всё работает, просто без запоминания.

## 8. Проверка
**Автотесты:** сопоставление регионов (Bavaria → Бавария, «Москва», старые написания), выбор места по координатам (30 км), деление снимка на уровни и размер `places.json`, группировка по уровням приближения, расстояние и «следующая рядом» (исключая текущую и чёрный список, переход в соседнее место), чёрный список (12 ч, истечение, недоступное хранилище), плеер на подставном `<audio>` (таймаут 8 с, обрыв, HLS-ветка, не-HTTPS), автовыбор режима, панель плеера и список (рендер, экранирование, клавиатура).
**Вручную:** 10 случайных станций разных стран (≥ 8 играют), мёртвая станция, сравнение с макетом 1440×900, телефон 390×844, вес первой загрузки.
